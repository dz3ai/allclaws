# AllClaws Virtual Team Research Output

This directory contains the committed work of each virtual team member.

## Structure
- `goclaw-operator/` — Infrastructure & governance analysis (GoClaw paradigm)
- `clawteam-lead/` — Architecture & coordination analysis (ClawTeam paradigm)
- `hermes-researcher/` — Research synthesis & cross-cutting analysis (Hermes paradigm)

## Source Material
Members draw from:
- AllClaws architecture docs (`../architecture/`)
- Platform source code (git submodules in parent repo)
- Published research and documentation

## Sprint Artifacts
Each member commits one markdown file per completed task, named:
`<member>/S1-T<task#>-<short-name>.md`
